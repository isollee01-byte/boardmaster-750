# 보드마스터 750

설치 의존성 없는 HTML/CSS/JavaScript 반응형 사이트입니다.

## 실행

이 폴더에서 `npm run dev` 실행 후 http://127.0.0.1:4173 에 접속합니다. `npm run check`로 JavaScript 구문을 확인합니다. 배포 대상은 `dist/`입니다.

## 구성

- `dist/index.html`: 제품 소개, 적용 도식, 규격, 시공 안내, FAQ, 문의
- `dist/styles.css`: PC/태블릿/모바일 레이아웃, 모바일 메뉴와 하단 고정 버튼
- `dist/app.js`: 메뉴, 문의 검증·복사, 설정된 API 전송
- `dist/config.js`: 실제 문의 API 설정
- `dist/privacy.html`: 개인정보 처리 안내 초안
- `dist/assets/product.svg`: 설명용 제품 일러스트. 실제 승인된 상품 이미지 확보 시 교체

## 운영 연결

현재 문의는 서버에 보내지 않고 사용자의 클립보드에 복사합니다. 온라인 접수 성공으로 표시하지 않습니다. 수신 API 및 개인정보 처리방침 승인 후 `config.js`의 `inquiryEndpoint`에 HTTPS URL을 넣고 `privacyApproved`를 `true`로 변경하면 접수 모드로 전환됩니다. 외부 API는 CORS를 허용해야 하며 서버에서 입력 검증·스팸 방지·안전한 보관·삭제를 구현해야 합니다. 실제 저장이 완료되었을 때만 JSON `{ "ok": true }`를 반환해야 합니다. 비밀 키를 프런트엔드에 넣지 마세요.

온라인 접수 활성화 전 `privacy.html`을 실제 운영 정책으로 교체하세요. 담당자, 보관기간, 수신처, 사업자 정보, 전화 운영 여부도 확정해야 합니다. 전화번호는 기획안에 따라 확인 전으로 표시하며 바로 전화 연결하지 않았습니다. 확인 후 `tel:0437607662` 연결을 추가할 수 있습니다.

시험 수치·성적서·인증 및 비교 성능 문구는 게시하지 않았습니다. 시공 수치와 시간은 승인 TDS/SDS/시방서가 확보되면 반영하세요. 설명용 제품 일러스트와 적용 도식을 실제 제품 사진·시공 사례로 표시하지 마세요.
